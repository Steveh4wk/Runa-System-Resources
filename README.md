# Runa System Resources

Raccolta di risorse per server FiveM.

## Risorse

### animal_farm
Gestione animali da fattoria e spawn animali selvaggi.

### fantasy_peds
Ped fantasy con sistemi per:
- Vampiri
- Licantropi (Lycan)
- Animagus

### fantasy_skilltree
Skill tree per personaggi fantasy con spell e poteri.

### ox_inventory
Configurazione inventario ox_inventory. Gli item devono essere aggiunti manualmente nel file data/items.lua.

### qb-metaldetecting
Sistema di metal detecting per trovare oggetti e tesori.

### Runa_System
Sistema principale con:
- Minigiochi
- Cutscene
- Sistema di crafting
- Interazione con NPC
- Gestione skin
- Audio e effetti

### stellare_watch
Orologio stellare con funzioni aggiuntive.

## Installazione

1. Copiare le risorse nella cartella resources del server
2. Aggiungere al file server.cfg
3. Configurare ogni risorsa secondo le proprie esigenze

## Note

- ox_inventory: aggiungere manualmente gli item in data/items.lua
- Alcune risorse richiedono dipendenze specifiche
